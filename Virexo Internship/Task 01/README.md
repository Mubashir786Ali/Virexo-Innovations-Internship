# Task 01 — Student Performance Prediction

## 📌 Overview
This task focuses on building a machine learning model to predict student academic outcomes based on lifestyle habits, behavioral patterns, and study metrics. The goal is to identify key factors influencing performance and early indicators of academic success.

---

## 🛠️ Key Features & Workflow
* **Dataset Processing:** Cleaned and structured key student indicators including daily study hours, attendance percentage, sleep duration, and previous GPA.
* **Exploratory Data Analysis (EDA):** Performed correlation analysis to understand how daily study habits and class attendance impact final grades.
* **Model Training:** Built and trained a classification algorithm to categorize academic outcomes.
* **Evaluation:** Evaluated performance using accuracy metrics, precision, recall, and confusion matrices.
