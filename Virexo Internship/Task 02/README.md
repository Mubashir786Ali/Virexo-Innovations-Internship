# Task 02 — Lead Conversion Prediction System

## 📌 Overview
This task focuses on building a predictive machine learning model to estimate the likelihood of sales leads converting into active customers. By scoring and prioritizing prospective leads based on user behavior and demographic signals, businesses can optimize sales strategies and resource allocation.

---

## 🛠️ Key Features & Workflow
* **Data Processing & Cleaning:** Handled missing values, formatted categorical features, and preprocessed behavioral metrics like website time spent and email interaction rates.
* **Exploratory Data Analysis (EDA):** Identified key conversion drivers using correlation heatmaps and distribution plots.
* **Model Training:** Implemented binary classification algorithms to calculate lead conversion probabilities.
* **Evaluation:** Assessed performance using Precision, Recall, F1-Score, and ROC-AUC curves to ensure balanced detection of potential conversions.
